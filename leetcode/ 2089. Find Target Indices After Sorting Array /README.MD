## 2089. Find Target Indices After Sorting Array

Нужно вернуть индексы элементов, равных `target`, в массиве после сортировки. Я сделал три решения.

### Решение 1. Ручная сортировка

Сортирую массив вложенными циклами: сравниваю элементы и меняю их местами, если они стоят не в том порядке. Затем прохожу по отсортированному массиву и, если текущий элемент равен `target`, добавляю его индекс в результат.

**Сложность:** время O(n²), память O(1) (не считая результата).

### Решение 2. Встроенная сортировка

Тот же алгоритм, но вместо ручных циклов использую готовую функцию (`sort.Ints` или `slices.Sort`). Она сортирует массив сама и делает это быстрее. После сортировки так же прохожу по массиву и собираю индексы элементов, равных `target`.

**Сложность:** время O(n log n), память O(1) (не считая результата).

### Решение 3. Без сортировки

За один проход по массиву считаю, сколько в нём элементов меньше `target` (`less`) и сколько больше (`more`). Количество элементов, равных `target`, получаю как `len(nums) - less - more`.

В отсортированном массиве сначала идут все элементы меньше `target`, затем равные ему. Поэтому первый индекс `target` равен `less`, а остальные идут подряд: `less`, `less+1`, ..., `less+equal-1`. Выделяю под них место в результате и добавляю эти индексы.

**Сложность:** время O(n), память O(1) (не считая результата).

### Итог

Решения 1 и 2 отличаются только способом сортировки, а решение 3 вообще обходится без неё и поэтому самое быстрое.
